# Security policy

yt-audio-mcp runs yt-dlp on input that comes from an AI agent, so input validation
and command execution matter.

Please **do not open a public issue** for security problems. Report them through
[GitHub's private vulnerability reporting](https://github.com/DaniilPak/yt-audio-mcp/security/advisories/new),
with the impact, the affected version and steps to reproduce. You'll get a reply
within a week.

Only the latest commit on `main` receives security fixes.
